# Instagram Telegram Downloader (MongoDB Version)

A Telegram bot to download Instagram posts using MongoDB for data storage.

## Features
- MongoDB integration
- User activity tracking
- Download history logging
- Error tracking

## Deployment
1. Create MongoDB Atlas cluster
2. Set environment variables:
   - `BOT_TOKEN`
   - `ADMIN_ID`
   - `MONGODB_URI`
3. Install requirements: `pip install -r requirements.txt`
4. Run: `python main.py`
